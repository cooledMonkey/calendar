## Консольный Календарь на Java 
Простое консольное Java-приложение, предназначенное для генерации и красивого вывода Григорианского календаря на любой год (начиная с 1600 года). Основная логика вычисляет смещение дней недели и корректно учитывает високосные года.

## Использованные инструменты
- Git
- Java
- JUnit5

## Входные данные
Год

## Выходные данные
Календарь на введенный год
